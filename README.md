# Design System - Help Desk

## Descripción

Este proyecto corresponde al desarrollo de una biblioteca de componentes UI (Design System) para un sistema de gestión de incidentes (Help Desk), utilizando HTML5 y CSS3.

## Componentes desarrollados

- Botón Primario
- Botón Secundario
- Botón Peligro
- Campo de texto (Input)
- Lista desplegable (Select)
- Tarjeta (Card)
- Badges de prioridad (Alta, Media y Baja)

## Tecnologías utilizadas

- HTML5
- CSS3

## Cómo ejecutar el proyecto

1. Abrir la carpeta del proyecto.
2. Ejecutar el archivo `index.html` en el navegador o con Live Server.
